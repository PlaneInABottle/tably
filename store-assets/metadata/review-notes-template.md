Create a dedicated reviewer account in the production Supabase project. Do not commit its password.

## Suggested Review Path

1. Sign in with the reviewer account.
2. The Explore tab opens in map mode. Move the map or tap Search this area to refresh results.
3. Open a table marker or switch to List to inspect details.
4. Use Create to publish a test table with a future time and map meeting point.
5. Open Plans to review confirmations and plan chat.
6. Open Profile, then Settings, to review notification and account controls.

## Notes

- Location permission supports nearby discovery and meeting-point selection.
- Notification permission supports plan and attendance reminders; the app remains usable if declined.
- Reviewers may create and cancel test tables.
- No paid features or in-app purchases are present in version 1.0.
